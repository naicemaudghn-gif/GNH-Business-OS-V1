# GNH Business OS V1

MVP de plateforme de gestion d'activité : dashboard, projets, tâches, CRM, rapports et GNH AI.

## Lancer localement

```bash
npm install
npm run dev
```

Ouvrir http://localhost:3000

Cette première version utilise des données de démonstration. La prochaine étape sera de connecter PostgreSQL et Prisma.
